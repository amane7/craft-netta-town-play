# クラフトネッタウン あそべるデモ

▶ **あそぶ：https://amane7.github.io/craft-netta-town-play/**

ネッタ万博（AICHI TECH DAY 2027）の展示で見つけた発見で、みんなの街が育つ Web アプリ「クラフトネッタウン」の体験版です。
サーバーなしで動き、記録はあなたのブラウザの中だけに保存されます（だれにも送られません）。
街を歩くほかの来場者は、架空のアバターです。

このリポジトリには、公開用に作ったページ（`index.html`）だけが入っています。

同梱ライブラリ：three.js (MIT)・Preact (MIT)・htm (Apache-2.0)・qrcode-generator (MIT, Kazuhiko Arase)。文字：Zen Maru Gothic・M PLUS Rounded 1c (SIL OFL)
