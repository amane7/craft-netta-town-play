# クラフトネッタウン あそべるデモ

▶ **あそぶ（来場者スマホの画面）：https://amane7.github.io/craft-netta-town-play/**

▶ **すべての画面（来場者スマホ・会場モニター・展示ブース・運営コンソール・通信テスト）：https://amane7.github.io/craft-netta-town-play/full/**

ネッタ万博（AICHI TECH DAY 2027）の展示で見つけた発見で、みんなの街が育つ Web アプリ「クラフトネッタウン」の体験版です。
サーバーなしで動き、記録はあなたのブラウザの中だけに保存されます（だれにも送られません）。
街を歩くほかの来場者は、架空のアバターです。

このリポジトリには、公開用に作ったページ（`index.html`・`full/index.html`）だけが入っています。運営コンソールもブラウザ内のまねで、本物の受付データにはつながりません。
